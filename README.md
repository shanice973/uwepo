# Uwepo Church Website

Official website for **Uwepo Church** (*Everyday In The Presence*), an apostolic ministry and the first expression of **Parousia Global**, led by **Pastor Ezekiel Musyoka & Faith Musyoka**.

## Core Pillars
- **Love** (Jn 3:16, Mat 22:37-39, 1 Jn 4:19)
- **Word** (Matthew 28:19-20)
- **Prayer** (Jer 33:3, Luke 18:1)
- **Supernatural** (1 Cor 4:20)

## Pages
- `index.html` — Homepage with pastor welcome, mission, and overview
- `about.html` — Church history, vision, mission, and core values
- `services.html` — Sunday & weekly service schedule
- `ministries.html` — Church ministries & Parousia Global overview
- `media.html` — Sermons, live streams, YouTube & Facebook
- `contact.html` — Contact info, visit planner, and message form
